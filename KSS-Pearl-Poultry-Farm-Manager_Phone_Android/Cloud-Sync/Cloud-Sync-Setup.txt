KSS PEARL POULTRY FARM - CLOUD SYNC SETUP (free, about 10 minutes, owner does this once)
Why: so workers sign in on THEIR OWN devices and the owner / admin sees every entry (deaths, feed, weights, vaccines) on the owner's devices.
Money data never goes to worker devices. Without cloud sync the apps still work on each device and you can exchange backup files.

PART 1 - Owner: create the sync service (one time)
1. On a computer, sign in to the farm's Google account and open script.google.com. Click New project.
2. Delete the sample code. Open the file Code.gs from this folder in Notepad, copy everything and paste it into the project. Click Save. Name it "KSS Pearl Sync".
3. Click Deploy > New deployment. Click the gear icon > Web app.
   Execute as: Me.   Who has access: ANYONE (not 'Only myself' and not 'Anyone with Google account': this is the most common mistake).   Click Deploy.
4. Click Authorize access, choose your Google account. If Google says "not verified": Advanced > Go to KSS Pearl Sync (unsafe) > Allow. (It is your own script.)
5. Copy the Web app URL. It ends with /exec. TEST IT: open it in a private/incognito window. You must see ok:true and 'KSS Pearl Poultry Farm sync' with NO sign-in page. If you see a Google sign-in page, go to Deploy > Manage deployments > pencil icon > Who has access = Anyone > Version: New version > Deploy.

PART 2 - Owner: connect the app
6. Open the app on the owner's device, sign in as owner. More > Cloud sync > paste the URL > press 'Test the URL first' (it says Connection OK or tells you what is wrong) > Connect and start syncing.
7. More > Team and access > add each worker (name + PIN).
8. More > Cloud sync > Worker connect code > Share on WhatsApp to each worker (or copy and paste). To use the app on your own second device (laptop AND phone) choose Owner-device code instead.

PART 3 - Workers: connect their own device
9. Install the app on the worker's phone. On the first screen open "Worker, or owner's second device?", paste the connect code, press Connect.
10. Sign in with the name and PIN the owner created. Workers can sign out and in at any time. Everything they record syncs to the owner when the phone has internet.

NOTES
- Keep each phone's date and time on Automatic. Sync keeps the newest entry when two devices edit the same record.
- If a phone is lost: More > Cloud sync > Change worker key, then send new codes. Disable or remove that worker under Team and access.
- Pop-up notifications and sound work while the app is open. A phone cannot ring if the app is fully closed.
- The data file is KSS_Pearl_Farm_Data.json in the owner's Google Drive. Still download a backup (More > Download full backup) every week.

ROLES (enforced by the sync service itself, with three secret keys)
- OWNER: everything, including Money (edit), accounts, the sync URL, backups and publishing software updates.
- ADMIN HELPER: works under the owner on batches, daily log, health, worker entries, stock and feed; can VIEW Money; cannot manage accounts, change the sync URL, edit money records or publish updates.
- WORKER (SHED): records deaths, feed, weights and health only; never receives money data.
In the app (owner): More > Cloud sync > Worker connect code, Admin helper code, Owner-device code. After removing or demoting an admin helper press Change admin key and send new admin codes.

SOFTWARE UPDATES (owner only)
More > App Updates & Software Releases: version, title, notes, audience (All users / Admins only / Workers only) and type (Critical / Feature / Maintenance), then Publish Software Update. Devices receive it when they sync; the owner sees who has acknowledged it. The sync service rejects publishing from admin and worker keys.

UPDATING AN EXISTING SETUP (after this release)
1. Open your Apps Script project, replace everything with the new Code.gs, press Save.
2. Deploy > Manage deployments > pencil icon > Version: New version > Deploy. The URL stays the same.
3. Reinstall the new apps (run the laptop installer again; host the new phone folder again). The first account on the owner's device becomes the Owner automatically.

WHAT'S NEW IN V1.9 (redeploy Code.gs as above: New version > Deploy)
- Chick orders (Batches page, owner/admin): record breed, quantity, supplier, order date and expected arrival; see days to arrival or an OVERDUE badge; Mark received can create the batch for you. Orders sync like all other records.
- Edit and Delete on every record (batches, daily records, deaths, weights, vaccines, treatments, stock/feed, expenses, sales, chick orders, team names). Owner/admin only; expenses, sales, batches and team names are owner only. Deletes sync to all devices and records do not come back.
- App update prompt: when publishing in More > App Updates, choose 'Is this a new app version? Yes' (optional download link, optional Force update). Every device that syncs and runs an older version sees an Update / Reload Now banner.
- Owner can change the sync link: More > Cloud sync > Sync link > Change sync link (Test connection first). Records on the device are kept; a new empty script is set up automatically with your keys.
